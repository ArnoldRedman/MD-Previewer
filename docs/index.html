MD Previewer

A small, local-first Markdown reader and quick editor. Rust + system WebView, no Electron, no telemetry, and no background update requests.

  • Tabs, session restore, file watching, search, zoom, print, and source editing
  • Tables, code highlighting, KaTeX, Mermaid, local images, and document links
  • Desktop plus native iOS and Android preview shells
