Markdown should open as fast as a text file

MD Previewer is a local-first Markdown reader and editor written in Rust on top of the system WebView. It ships no browser engine, opens on double click, and renders everything on your machine.

  • Windows 10 / 11
  • ~5 MB installer
  • No Electron
  • No telemetry, no account
  • Offline math and diagrams
  • MIT licensed

Interface

Read, edit, and compare in one window

Folder and recent files on the left, document in the middle, tabs on top. Nothing else competes for attention.

Features

Built for people who read a lot of Markdown

Long AI-generated documents, chapter files inside a writing project, a .md that arrived from your phone — heavy editors are slow for these, and a plain text editor shows you no structure.

Opens anything readable

Not just .md: any plain-text file — .txt, .json, .log, source code — opens directly. An 8 KB binary sniff stops you from opening an executable or archive by accident.

Edit whenever you want

Ctrl+E flips between preview and source, Ctrl+\ puts them side by side. Edits preview live and save straight back to the original file.

Search and outline

Ctrl+F highlights matches in the document and steps through them; the sidebar builds an outline from your headings and follows the scroll position.

Tabs and split views

Keep several documents open, and get your tabs back the next time you launch. The same file can also be opened in two windows for a side-by-side comparison.

Keeps up with the file

When another program rewrites the file on disk, the view reloads itself. If you happen to have unsaved changes, it surfaces the conflict and asks what to do instead of overwriting.

Encoding handled for you

Detects UTF-8, UTF-8 BOM, GBK / ANSI and UTF-16 LE/BE. If an old file still shows as garbage, reopen it with a chosen encoding or convert it and save as a new file.

Math, diagrams, highlighting

KaTeX math, Mermaid flowcharts and sequence diagrams, and syntax highlighting all ship inside the installer. They render offline, and every code block has a copy button.

Light, dark, and typography

Follows the system theme, or force light/dark. Zoom level is remembered, and long tables or code lines can be wrapped with one toggle.

Quiet by design

No data collection, no analytics, no account, and no network request when you open a document. The only time it goes online is when you ask it to check for updates.

Updates itself

When a new version exists, the app downloads it with a visible progress bar and swaps itself in on restart — no hunting for the installer again.

Author mode

For long-form writers: fold away author notes and chapter numbering so only clean prose remains. One switch in the settings panel.

Print and save as

Ctrl+P goes through the native print path rather than a browser dialog, and Ctrl+Shift+S saves a copy with an encoding of your choice.

Install

Three steps

1 · Download

The installer associates .md files with MD Previewer, so a double click opens the document and registers an uninstaller.

2 · If SmartScreen complains

Builds are not code signed yet, so Windows may show "unknown publisher". Choose "More info" → "Run anyway"; the release also ships a SHA-256 checksum file.

3 · Or use the portable build

MD-Previewer-windows-x64.exe is a single file that runs from any folder. Uninstalling means deleting it.

Requirements: Windows 10 1809 or newer (any Windows 11 build). Rendering uses the WebView2 runtime that ships with Windows; builds older than 1809 may need the WebView2 runtime installed once.

Mobile

A .md that arrives on your phone still opens

iOS and Android each have a read-only shell that shares the same rendering rules. Pick MD Previewer from "Open with" in Files, WeChat or any other app and the document is laid out properly — no editor required on the phone. The Android package is published and installable; the iOS shell has to be built with Xcode for now.

Android

A native WebView shell that responds to ACTION_VIEW and share intents. Download MD-Previewer-mobile.apk — allow installs from unknown sources; the package declares no network permission at all.

iOS

UIKit + WKWebView, handles the system "open in" flow. Build it from mobile/ios with Xcode; no binary is published yet.

Read-only and quiet

The mobile shells are meant to be opened, read and closed: no sign-in, no uploads, no ads.

FAQ

Things worth checking first

Does it send my documents anywhere?

No. Rendering, search, math and diagrams all happen locally. The app only touches the network when it checks GitHub for a release (and you can ignore that entirely). No analytics, no telemetry, no account.

Why does it open large files faster than a code editor?

Because it does not ship Chromium: the interface runs on the WebView your operating system already provides, the installer is a few megabytes, and start-up does not have to boot a browser engine first.

Can I use it as an editor?

Yes — source editing, live preview, split view, save as and encoding conversion are all there. It is not an IDE: no plugin ecosystem, no Git panel. If what you want is "look quickly, fix quickly", that trade is the point.

An old file is GBK-encoded and shows as garbage

Click the encoding label under the tab bar and pick "Reopen with" that encoding, or choose "Convert to" and save with Ctrl+S.

How does this relate to upstream MD Preview?

It is a fork of MD Preview with its own branding and release/update channel, kept under the MIT license.
